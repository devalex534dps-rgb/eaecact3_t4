# Act2. Spring MVC - Vistas con Thymeleaf, DTOs y Manejo de Peticiones

Proyecto CRUD Backend con vistas (thymeleaf) para el frontend, con conexion a base de datos.

## Funcionamiento
El proyecto esta desarrollado en spring con sus respectivas clases `@Entity` para la representacion (obtener los datos de la base de datos), las clases tienen el mismo nombre que las vistas sql, clases `@Repository`, `@Service` y `@Controller` para el flujo de datos hasta la renderizacion en html con la ayuda de thymeleaf.

### Despliegue
El proyecto se encuentra desplegado y funcionando correctamente en este [link](https://veterinariabobby.tech/eaecact3_t4/) .
